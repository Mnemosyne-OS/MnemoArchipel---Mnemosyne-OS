# Avatar Studio Customization System

The custom avatar is rendered dynamically from a JSON structure (`AvatarStudioConfig`):

## Customizable Attributes

* **Face Shape**: 5 distinct facial structure variants (Classic, Long, Square, Triangle, Chubby/Joufflu).
* **Skin Tone**: Customizable skin base color, adjustable via a full RGB spectrum color picker.
* **Expression & Emotions**: 8 mouth variants (Smile, Laugh, Surprised, Mustache, Sad, Angry, Neutral, Fear) paired with expressive eyebrows (sad, angry, curved).
* **Orbital Accessories**: Up to 5 animated accessories floating in circular orbit paths around the head.
